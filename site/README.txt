SimGolf Mobile — Alpha version 1.2

An unofficial mobile adaptation preserving original SimGolf gameplay.
This project is not affiliated with the original game's creators or rights holders.

INSTALL
Open golf.html or this site's entry page in normal Safari over HTTPS.
Use Choose Files to select your own original disc image AND the matching game
executable. They are processed locally, not uploaded. A disc alone is not enough.

Current validated input pair: original rerelease disc image plus the v1.02
executable whose SHA-256 is:
21c98fa5ffa0a552543a09f6ca0a58eed4b666d2646f02ea0a93cf8d53d80ca1
The developer's own file is named golf_nocd.exe. A v1.02 label or that filename
alone does not establish compatibility. We cannot supply original game files
or guarantee other editions work. On an incompatible-input error, stop and
report your edition/version; do not obtain a replacement from this website.
ISO+EXE installation has local/maintainer acceptance. ZIP/7z/RAR selection is
present but not yet independently accepted on iPhone. The original opening plays from your imported local files. Use ?novideos only to skip movies for diagnostics.

DEVICE
Maintainer-tested device: iPhone15 Pro Max, reported iOS27.0.1, Safari/Home Screen.
The app needs WebAssembly JSPI and private file storage; unsupported browsers
receive an error. The maintainer also reports smooth panning/zooming on the unfolded Duo.
Other devices/iOS versions are part of the pilot, not guaranteed.

AFTER INSTALL
Add to Home Screen after installation works. Keep a copy of your saves in Files.
Save game stores progress inside this site's browser storage.
System > Save files / backup downloads/imports actual saved games.
Moving to a different website/address requires explicit save export/import.
Clearing site data can remove your installed originals and local saves.
Once app resources are stored, offline Home Screen launches/play/saves are
accepted on the maintainer's phone. Close/reopen is needed for a real cold test.

UPDATES
Download a save backup first. Use Check for updates on the welcome or title menu. If an update is downloaded, save and close all
app windows/tabs at this address, then reopen. Verify the new build label and
load your save. Updates do not intentionally clear original files or saves.
Keep the previous backup until the new version has loaded/saved successfully.

PILOT TEST
Record exact version/build, device/iOS, Safari or Home Screen and orientation.
Try installation, new/load, Pan/pinch/rotation, construction, a round, save/load,
backup export/import and offline cold reopening. Report expected/actual behavior,
course/in-game date and whether Menu still responds. Do not post original game
files, executables, archives, credentials or private saves in public channels.
Use the maintainer's Discord bug-report instructions. Stop and retain a backup
if a save disappears or the game freezes. Do not clear site data as a first fix.

KNOWN LIMITATIONS
This is alpha software with incomplete device/input-edition and long-session
coverage. SimFoto/year-end/tournament/progression edge cases remain test areas.
Storage quota, eviction, forced termination and multi-window write conflicts
are not guaranteed recovered by the controlled desktop failure tests.
Use only one game window/tab at a time: simultaneous clients can overwrite
each other's save inventory. Keep exported backups. Original opening video is
now supported locally; broader phone playback and archive acceptance are pending.

PRIVACY
The host receives ordinary app-resource requests. Original game files and saves
are processed/stored in your browser. This static candidate has no automatic
game/save upload, crash-report endpoint or analytics integration. A bug report
you submit is separate. Your browser/OS controls storage and file backups.
