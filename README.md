# SimGolf Mobile — Alpha version 1.0

An unofficial, experimental mobile adaptation preserving original SimGolf gameplay.

**[Open the alpha](https://fourtempers-code.github.io/sgmobile-alpha/)**

Players must provide their own supported original game files; installation happens locally in the browser. Original game assets, executables, DLLs, mapped original images and saves are not included in this repository. This project is not affiliated with the original game’s creators or rights holders.

Use Safari on iPhone and follow the installer instructions. After installation, add the app to your Home Screen. Export save backups regularly. This is alpha software with incomplete device, edition and long-session coverage.

Selected build: `alpha100-github-pilot-v1-20261021T175651Z`.

Deployment is manual from main. The workflow verifies the complete app inventory and uploads only `site/`; a push alone does not deploy. The site link becomes available after the first deployment completes.
